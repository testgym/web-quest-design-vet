# EDU.LAB — інтерактивні вебквести для професійної освіти

Навчальна платформа на Vue 3, TypeScript і Vite для теми магістерської роботи **«Педагогічні умови проєктування вебквестів для здобувачів професійної освіти»**. Спільна професійна ситуація — фішинг, робочі повідомлення та захист акаунта в навчальній майстерні. Шість методик визначають різні практичні дії, підтримку й результати учня.

## Шість навчальних майстерень

| Методика | Практична робота | Педагогічний механізм |
| --- | --- | --- |
| Таксономія Блума | Сортування повідомлень, дослідження доказів, симуляція захисту та власна інструкція | Шість послідовних рівнів від пригадування до створення авторського матеріалу. |
| Mastery Learning | Опрацювання цільових умінь, корекція та нові випадки для перевірки | Критерії кожного уміння мають бути виконані повністю. Загальний відсоток не замінює опанування. |
| Зона найближчого розвитку | Три кейси з наставником, дозованими підказками та фінальним самостійним виконанням | Опори поступово зменшуються; результати з підтримкою й самостійні дії відображаються окремо. |
| SOLO | Пошук фактів, побудова причинних зв’язків і перенесення узагальнення | Ускладнюється структура пояснення: від окремих ознак до цілісної моделі та нового контексту. |
| Дев’ять подій Ганьє | Навчальний інцидент із демонстрацією, практикою, зворотним зв’язком та перенесенням | Дев’ять подій організовують повний цикл навчання; інформаційні етапи поєднано з діями учня. |
| Адаптивний маршрут | Чергування розбору повідомлень, цифрових доказів і дій у симуляції | Наступний кейс змінює складність за попередніми діями та охоплює різні вміння. Це навчальна адаптація за правилами. |

Учасник працює з макетами повідомлень, складає карту доказів, виконує дії в симуляції, пише власні матеріали й рефлексію. Довідник містить джерела для дослідження. Чернетка проходження зберігається для активного локального профілю.

## Результат і портфоліо

Результат показує критерії кожного етапу, журнал дій, використані підказки, повторні спроби, самостійні етапи, авторські матеріали й рефлексію. Портфоліо можна завантажити як текстовий файл UTF-8.

Тренажер перевіряє конкретні дії та наявність матеріалів. Відсоток означає частку виконаних критеріїв практичних дій. Авторські матеріали й самоперевірка за відкритою рубрикою зберігаються окремо та не збільшують цей відсоток. Зміст аргументації, причинні пояснення та якість авторського тексту потребують обговорення з викладачем.

Маршрут можна закінчити з прогалинами й отримати портфоліо для вдосконалення. Мета позначається досягнутою після виконання всіх потрібних дій, заповнення власних матеріалів, самоперевірки та рефлексії. Самоперевірка підтверджує роботу учня, а не автоматичну перевірку змісту тексту.

У Mastery Learning кожне уміння проходить цикл «тренування → новий самостійний випадок → наступне уміння». Після помилки на тренуванні можна виправити дії. Перевірочний випадок фіксує першу спробу; повне опанування потребує самостійного виконання всіх перевірочних випадків. Для нової перевірки почніть нове проходження. Повторне проходження зберігає раніше досягнуте завершення. Найкращий відсоток і останнє портфоліо відображаються окремо.

## Запуск

Потрібні Node.js **22.18+** або **24.12+** та npm.

```bash
npm ci
npm run dev
```

Відкрийте адресу Vite, зазвичай `http://localhost:5173/`.

```bash
npm run type-check
npm test
npm run build
npm run preview
```

`npm run build` перевіряє типи й створює статичний каталог `dist/`. Для локального перегляду збірки використовуйте `npm run preview`.

## Структура

- `src/data/methods/*.json` — теоретичні описи методик, принципи та педагогічні джерела.
- `src/data/activities.ts` — типи, шість інтерактивних маршрутів, професійні сценарії, критерії та поля авторських матеріалів.
- `src/components/ActivityWorkbench.vue` — інструменти практичної роботи.
- `src/components/QuestView.vue` — послідовність етапів, корекція, підтримка, адаптація й чернетки.
- `src/data/assessment.ts` — перевірка дій і формування критеріїв.
- `src/data/quest-flow.ts` — добір адаптивних випадків, цикли опанування та підсумки.
- `src/components/ResultsView.vue` — критерії, журнал, рефлексія та експорт портфоліо.
- `src/components/LessonView.vue` — теорія й опис практичної роботи для обраної методики.
- `src/App.vue` — навігація, локальні профілі й версії прогресу.

## Локальні дані

Профілі, портфоліо й чернетки зберігаються в `localStorage` цього браузера на цьому пристрої. Профілі не мають паролів або синхронізації між пристроями. Очищення даних сайту видалить їх.

- Профілі: `edulab.profiles.v1`.
- Прогрес інтерактивних маршрутів: `edulab.progress.interactive.v2.<profile>`.
- Чернетки: `edulab.quest.interactive.v2.<profile>.<method>`.
- Попередній прогрес тестів зберігається в оригінальних ключах і копіюється до `edulab.progress.archive.interactive.v2.<profile>`. Раніше створені архіви `edulab.progress.archive.v1.<profile>` також зберігаються.

Попередні відсотки тестів не враховуються в нових інтерактивних маршрутах. Імена й активний локальний профіль зберігаються під час переходу.

## Публікація

Workflow `.github/workflows/deploy.yml` збирає й публікує `dist/` на GitHub Pages після `push` до `main`. У налаштуваннях репозиторію виберіть **Settings → Pages → Build and deployment → GitHub Actions**. Відносний `base` у `vite.config.ts` підтримує розміщення в підкаталозі Pages.
