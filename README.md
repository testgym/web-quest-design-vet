# EDU.LAB — вебквести з кібербезпеки за педагогічними методиками

Навчальна платформа на Vue 3, TypeScript і Vite. Шість маршрутів навчають однієї теми — **фішинг і захист облікового запису**. Учасник ухвалює рішення в кіберситуаціях; запитання не вимагають від нього називати педагогічні терміни. Методика визначає структуру проходження:

| Методика | Як працює квест |
| --- | --- |
| Таксономія Блума | Шість послідовних рівнів: від пригадування ознак до створення плану захисту. |
| Mastery Learning | Три діагностичні завдання. Якщо є помилка, учасник отримує корекцію та три нові рівноцінні завдання. Критерій опанування — три правильні рішення з трьох. |
| Зона найближчого розвитку | Кейси ускладнюються; підказки відкриваються за потреби, після помилки можлива повторна спроба. |
| SOLO | П’ять етапів поступово ведуть від окремої ознаки до пов’язаного пояснення й перенесення правила. |
| Дев’ять подій Ганьє | Маршрут проходить дев’ять навчальних подій: увага, мета, пригадування, пояснення, орієнтир, практика, зворотний зв’язок, перевірка та перенесення. |
| Адаптивне тестування | Навчальна симуляція добирає наступне завдання з банку за складністю попереднього рішення. Це спрощена модель, не психометричний CAT. |

Після відповіді користувач отримує пояснення. Результат показує бал, час, сильні та слабкі місця. Квест можна перервати й продовжити з того самого кроку.

## Запуск

Потрібні Node.js **22.18+** або **24.12+** та npm.

```bash
npm ci
npm run dev
```

Відкрийте адресу, яку виведе Vite, зазвичай `http://localhost:5173/`.

```bash
npm run type-check
npm run build
npm run preview
```

`npm run build` перевіряє типи та створює статичний каталог `dist/`. Для локального перегляду збірки використовуйте `npm run preview`, а не `file://`.

## Дані й прогрес

- Кожна методика описана окремим JSON-файлом у `src/data/methods/`. Поле `quest` задає тему, місію, режим і етапи; `quiz` містить практичні завдання. `src/data/methods.ts` завантажує файли в порядку числових префіксів.
- `src/components/QuestView.vue` реалізує проходження та логіку методик. `ResultsView.vue` показує результат, `LessonView.vue` — довідку про методику.
- У застосунку можна створювати локальні профілі з іменами. Прогрес і незавершені квести кожного профілю зберігаються окремо в `localStorage` **цього браузера на цьому пристрої**. Це не облікові записи: немає пароля, сервера чи синхронізації між пристроями. Очищення даних сайту видалить ці профілі.
- Попередні результати старих тестів, якщо вони були, залишаються в `edulab.progress.v1` та копіюються до архівного ключа. Вони не враховуються в нових квестах, бо вимірювали інші завдання.
- Усі матеріали та правильні відповіді є в клієнтській збірці. Платформа призначена для навчання й самоперевірки, а не захищеного іспиту.

## Публікація

Workflow `.github/workflows/deploy.yml` збирає й публікує `dist/` на GitHub Pages після `push` до `main`. У налаштуваннях репозиторію виберіть **Settings → Pages → Build and deployment → GitHub Actions**. У `vite.config.ts` налаштовано відносний `base`, тому збірка працює і в підкаталозі Pages.
